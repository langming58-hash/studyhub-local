# Release Announcement

StudyHub Local v0.1.4 is the first version I am comfortable sharing broadly.

It includes:

- local course/week organization
- synthetic Demo Mode
- local search
- optional source-grounded OpenAI integration
- teacher-question safety
- read-only MCP
- localhost/privacy boundaries
- Host-header and DNS-rebinding protection
- exact same-origin checks
- active-content preview isolation
- privacy and security acceptance tests in CI

It is still early-stage, and feedback is welcome.
