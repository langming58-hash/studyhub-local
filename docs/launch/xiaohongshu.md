# 大学课程资料太乱，我给自己做了一个本地 Study Hub

大学里的 PDF、PPT、Tutorial、Lab、Quiz 很容易越堆越乱，所以我做了一个开源早期版本：StudyHub Local。

它可以把资料按 Course -> Week 整理，分成 Materials / Exercises，本地搜索，也可以在可选开启 OpenAI 后让 AI 基于自己的资料回答，并显示来源。

几个我很在意的点：

- 默认 Demo Mode，不需要 API key
- 课程文件留在自己电脑
- localhost only
- 默认没有 telemetry
- Practice 题不让 AI 乱编，只能从材料里找
- 仓库只放合成 demo，不放真实课程资料
