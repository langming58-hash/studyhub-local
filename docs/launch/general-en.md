# General English Launch Copy

I released StudyHub Local, an early-stage open-source, local-first study material hub.

It is built for the messy reality of course PDFs, slides, tutorials, labs, quizzes, notes, and code files. StudyHub Local organizes a local study folder by Course -> Week -> Materials / Exercises, builds a SQLite metadata index, and provides a localhost web UI for browsing, search, practice records, and optional source-grounded AI.

Demo Mode is enabled by default and works without an OpenAI API key. OpenAI integration is optional, server-side, and designed to return cited answers from indexed material. The app has no telemetry by default, refuses non-loopback binding, keeps course files outside the repository, and includes a read-only MCP boundary for local integrations.
