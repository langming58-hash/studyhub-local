# General English Launch Copy

StudyHub Local v0.3.0-beta.2 is available as a macOS prerelease: a local-first workspace for reading course PDFs, keeping source-linked notes and reviewing what you learn.

PDF Reader V1, saved PDF text excerpts, user-authored FSRS review cards, local search and course/week organization work locally. Canvas OAuth, Assignments and Today are included; connecting Canvas requires an institutionally provisioned OAuth client. AI is optional, and enabling cloud AI/indexing sends selected content to the configured provider.

Local backup export and Restore Preview / Apply / Undo are implemented with bounded validation. Seven core macOS learning workflows passed user testing as reported by the maintainer; full real-GUI backup save/restore/undo acceptance remains incomplete. PDF Highlights from unmerged PR #44 are excluded.

Apple Silicon only, macOS 13+. Ad-hoc signed, not Developer ID signed or Apple notarized; first-run Gatekeeper approval may be needed. This is a prerelease, not a stable production release. The backend is bundled; end users do not need Python, Node.js, Rust or Terminal.

The [product gallery](https://github.com/langming58-hash/studyhub-local#from-reading-to-review) contains genuine beta.2 screenshots using an isolated synthetic library. Fictional examples are not bundled into the app; first launch is empty. Original files stay under the user's control. Backups exclude originals and credentials and may contain private notes; keep separate copies of original files.
