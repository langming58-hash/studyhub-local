# 通用中文发布文案

我做了 StudyHub Local，一个开源、本地优先的大学学习资料管理器。它可以把课程文件按 Course -> Week 整理成 Materials / Exercises，支持本地全文搜索、Practice / Wrong Questions 记录，也可以在可选开启 OpenAI 后让 AI 基于你的资料回答并显示来源。默认 Demo Mode，不需要 API key；课程文件留在本机；服务只监听 localhost；默认没有 telemetry。现在是早期版本，欢迎试用、提 Issue、PR 和反馈。

Release: https://github.com/langming58-hash/studyhub-local/releases/tag/v0.1.4
