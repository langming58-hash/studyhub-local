# 通用中文发布文案

我做了 StudyHub Local，一个开源、本地优先的大学学习资料管理器。它可以把课程文件按 Course -> Week 整理成 Materials / Exercises，支持本地全文搜索、Practice / Wrong Questions 记录，也可以在可选开启 OpenAI 后让 AI 基于你的资料回答并显示来源。第一次打开是干净的空工作区；不开 OpenAI 也能使用本地整理、预览、搜索、笔记和学习记录。课程文件留在本机，服务只监听 localhost，默认没有 telemetry。现在是早期版本，欢迎试用、提 Issue、PR 和反馈。

Repo: https://github.com/langming58-hash/studyhub-local

Release: https://github.com/langming58-hash/studyhub-local/releases/tag/v0.2.0
