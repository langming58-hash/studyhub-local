# 通用中文发布文案

StudyHub Local v0.3.0-beta.2 已提供 macOS 预发布版本：在本地阅读课程 PDF、保存关联来源的笔记，再用复习卡片巩固所学。

本版本包含 PDF Reader V1、PDF 文本摘录、手动 FSRS 复习卡片、本地搜索与课程/周次整理。Canvas OAuth、作业与 Today 已包含，但连接需要学校配置 OAuth 客户端。AI 为可选功能；启用云端 AI 或索引会将选中的内容发送给所配置的提供商。

已实现本地备份导出、恢复预览、应用和撤销，并按验证范围执行。维护者报告七项 macOS 核心学习流程已通过用户测试；完整的真实 GUI 备份保存、恢复和撤销验收仍未完成。不包含尚未合并的 PR #44 PDF Highlights。

仅支持 Apple Silicon、macOS 13+。仅 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证，首次启动可能需要 Gatekeeper 批准。这是预发布测试版，不是稳定生产版本。App 内置后端，普通用户无需安装 Python、Node.js、Rust 或终端工具。

[产品截图](https://github.com/langming58-hash/studyhub-local/blob/main/README.zh-CN.md) 来自真实 beta.2 App 的独立合成资料库，所有示例均为虚构，不会随 App 分发。首次启动是空工作区。原始文件由用户自己保管；备份不包含原始文件或凭证，可能包含私人笔记，请单独保留原始文件。
