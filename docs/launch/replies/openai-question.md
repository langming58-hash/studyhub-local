# OpenAI Question

OpenAI is optional. The app runs without an API key in Demo Mode and still supports local browsing, search, source previews, and practice records.

If OpenAI is configured, the integration is server-side. The key should stay in `.env.local` or the server environment, never in frontend code, screenshots, logs, issues, or GitHub.

The Ask AI path is designed to use narrow context first and cite source material instead of answering from nowhere.
