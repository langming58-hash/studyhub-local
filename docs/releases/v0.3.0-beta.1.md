# StudyHub Local v0.3.0-beta.1

This prerelease is the first public macOS DMG for StudyHub Local.

## Download

Download `StudyHub-Local-v0.3.0-beta.1-macos-arm64.dmg` and its matching `.sha256` file from the assets below.

## Compatibility

- Apple Silicon only (`arm64`)
- macOS 13 Ventura or later
- Unsigned beta
- Not notarized

## Install

1. Download and open the DMG.
2. Drag StudyHub Local to Applications.
3. Try to launch it normally.
4. If macOS blocks the unsigned beta, open System Settings -> Privacy & Security and choose Open Anyway for StudyHub Local.

Do not disable Gatekeeper. Git, Node.js, Python, Rust, npm, and Terminal are not required.

## Included

- Local course, week, material, and exercise organization
- Local preview and search
- Notes and study records
- Optional source-grounded OpenAI integration
- Bundled local backend
- English and Simplified Chinese UI

This remains an early beta. Please [report issues](https://github.com/langming58-hash/studyhub-local/issues/new/choose) without attaching private course files, API keys, local databases, or personal paths.
