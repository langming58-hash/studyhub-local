# Roadmap

StudyHub Local is early-stage. These directions are intentionally not tied to
dates.

## v0.3.0 Milestone

The current development milestone focuses on product comprehension and a
coherent local study loop. It is tracked in public issues and is not a published
release yet.

- Study Engine for material progress, review flags, and a deterministic queue ([#9](https://github.com/langming58-hash/studyhub-local/issues/9))
- Synthetic populated product gallery for the README ([#10](https://github.com/langming58-hash/studyhub-local/issues/10))
- Search ranking and filtering refinements ([#2](https://github.com/langming58-hash/studyhub-local/issues/2))
- Human keyboard and screen-reader follow-up ([#4](https://github.com/langming58-hash/studyhub-local/issues/4))

## Later Areas

- Cross-platform launcher and installer polish
- Better automatic dependency handling for Poppler and LibreOffice
- Richer document extraction, including scanned-PDF/OCR workflows and workbook previews
- Deeper browser navigation and shareable local deep links
- Human VoiceOver and keyboard-navigation audit
- Cleaner import adapters for learning-management systems
- User-owned export and backup tools for notes/history/review data

## Principles

- Keep original study files as the local source of truth
- Keep synthetic fixtures test-only and out of production bundles
- Avoid telemetry by default
- Do not generate practice questions
- Keep optional AI source-grounded and clearly cited
