# Development

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run test
npm run build
npm run ci
```

## Fixture Policy

Use only synthetic fixture files in `demo-data/` and tests. Do not use real course materials, teacher questions, official solutions, private answers, or screenshots that show personal data.

## Branches

Use short feature branches and focused pull requests. Include privacy/security impact in every PR.
